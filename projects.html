Smart Resume Analyser

AI-assisted resume scoring, feedback, and job-matching platform

Upload a PDF or scanned resume and get an OCR + NLP score, an ATS-compatibility check, job-description matching, and an in-app Gemini assistant.

Python Flask Postgres NLTK PyMuPDF Tesseract OCR Google Gemini API Docker Render HTML/CSS/JS

A full-stack Flask application that takes a candidate's PDF or scanned-image resume, extracts its text via OCR and PDF parsing, and analyses it with NLP to produce a scored, section-by-section breakdown — skills, education, experience, and formatting — with an ATS-compatibility check and concrete suggestions for improvement. It also matches a resume against a pasted job description, generates personalised career feedback, and surfaces trends across every resume analysed on an analytics dashboard. A guided resume builder lets users compose one from scratch with structured, repeatable work-experience and education entries, an in-app AI assistant (Google Gemini) that reviews the draft for gaps and rewrites weak sections on request, and one-click export to a genuinely ATS-parseable PDF with real embedded text rather than a rasterised image. Deployed on Render's free tier against an isolated Postgres schema (Neon) — the first request after a period of inactivity can take up to a minute to wake the instance.

  • OCR + PDF text extraction (PyMuPDF, Tesseract) so both scanned images and native PDFs work
  • NLP-driven skill extraction and section scoring (NLTK tokenisation, stopword filtering, tagging)
  • ATS-compatibility simulation with a transparent, explainable scoring breakdown
  • Job-description matching to rank a resume's fit against a specific role
  • Personalised feedback generation based on career goal, experience level, and target role
  • Guided resume builder with an in-app AI assistant (Google Gemini) that flags gaps in the draft and applies suggested rewrites in one click
  • Native-text PDF export — real embedded text via direct PDF drawing, not a rasterised image, so builder output is actually machine-readable by real ATS software
  • Auth system with email-based password reset (SendGrid) and per-user history
  • Analytics dashboard (score distribution, top skills, career-field breakdown) with CSV/JSON export for Power BI

A full-stack dental clinic platform — appointment booking with genuine double-booking prevention, automatic confirmation and reminder emails, a staff-managed doctor directory, patient records with role-based access, and a retrieval-augmented chatbot that only ever answers from the clinic's own documents and refuses to give medical advice. Deployed live (Vercel + Render), with 382 tests (268 backend, 114 frontend) and a CI pipeline running both suites on every push.

  • Appointment booking that rejects real conflicts via a half-open interval check, enforced at the database with a partial unique index — not just an application-level check
  • A RAG chatbot grounded in the clinic's own documents (sentence-transformer embeddings, cosine retrieval, a confidence threshold below which it says "I don't know" instead of guessing), streamed token-by-token
  • An auto-regenerating "Dentist & Department Directory" document, chunked one entity at a time so retrieval doesn't dilute across multiple doctors — the chatbot's knowledge base never goes stale when staff update the directory
  • Role-based access (patient / staff / admin / owner) as a signed JWT claim, refreshed on token refresh so a role change takes effect on next login
  • 382 tests (268 backend + 114 frontend), GitHub Actions CI on every push

A personal expense tracker rebuilt as a Flask JSON API (SQLAlchemy + JWT auth) behind a React Native / Expo (TypeScript) app, deployed for real: the API runs on Render against a Postgres database (Neon), the web build is deployed on Vercel, and the app itself also ships as an installable Android APK via EAS Build — not just a localhost demo. Light/dark theming, animated charts, a SendGrid-backed forgot-password flow, CSV export, and quick-add templates round out the UX.

  • JWT-authenticated Flask REST API (SQLAlchemy + Flask-Migrate) against Postgres, deployed on Render via Docker
  • React Native / Expo mobile app — bottom-tab navigation, animated dashboard charts, category filtering, budget tracking
  • Per-user currency preference (12 ISO 4217 codes) persisted server-side, driving every amount shown across the app
  • Light/dark theme with persisted preference, swipe-to-delete on native (a dedicated delete action on web), CSV export, pull-to-refresh, and haptic feedback
  • Forgot/reset password flow — a SendGrid-emailed one-time code, hashed and single-use server-side, no account enumeration
  • Real Android APK built and distributed via EAS Build, not just an Expo Go preview
  • Web build (Expo for Web) deployed on Vercel, hitting the same Flask API through a locked-down CORS allowlist
  • CORS allowlist and per-endpoint rate limiting on auth routes; pytest suite covering auth, ownership isolation, and CRUD
