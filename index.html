Smart Resume Analyser

AI-assisted resume scoring, feedback, and job-matching platform

Source Code ↗

A full-stack Flask web application that takes a candidate's PDF or scanned-image resume, extracts its text with OCR and PDF parsing, and analyses it with NLP to produce a scored, section-by-section breakdown — skills, education, experience, and formatting — with an ATS-compatibility check and concrete suggestions for improvement. It also matches a resume against a pasted job description, generates personalised career feedback, and includes a guided resume builder and an analytics dashboard summarising every resume analysed so far.

  • OCR + PDF text extraction (PyMuPDF, Tesseract) so both scanned images and native PDFs work
  • NLP-driven skill extraction and section scoring (NLTK tokenisation, stopword filtering, tagging)
  • ATS-compatibility simulation with a transparent, explainable scoring breakdown
  • Job-description matching to rank a resume's fit against a specific role
  • Personalised feedback generation based on career goal, experience level, and target role
  • Auth system with email-based password reset (Flask-Mail) and per-user history
  • Analytics dashboard (score distribution, top skills, career-field breakdown) with CSV/JSON export for Power BI
Python Flask SQL Server NLTK PyMuPDF Tesseract OCR Flask-Mail HTML/CSS/JS

Floss Clinic

Dental clinic platform with real conflict-safe booking and a grounded RAG chatbot

Live Demo ↗ Source Code ↗

A full-stack dental clinic platform — appointment booking with genuine double-booking prevention, a staff-managed doctor directory, patient records with role-based access, and a retrieval-augmented chatbot that only ever answers from the clinic's own documents and refuses to give medical advice. Deployed live (Vercel + Render), with 332 tests (233 backend, 99 frontend) and a CI pipeline running both suites on every push.

  • Appointment booking that rejects real conflicts via a half-open interval check, enforced at the database with a partial unique index — not just an application-level check
  • A RAG chatbot grounded in the clinic's own documents (sentence-transformer embeddings, cosine retrieval, a confidence threshold below which it says "I don't know" instead of guessing), streamed token-by-token
  • An auto-regenerating "Dentist & Department Directory" document, chunked one entity at a time so retrieval doesn't dilute across multiple doctors — the chatbot's knowledge base never goes stale when staff update the directory
  • Role-based access (patient / staff / admin) as a signed JWT claim, refreshed on token refresh so a role change takes effect on next login
  • 332 tests (233 backend + 99 frontend), GitHub Actions CI on every push
Python Flask SQLAlchemy React Vite sentence-transformers

Expense Tracker

Flask REST API + React Native app, deployed to Android and the web

Live Demo ↗ Source Code ↗

A personal expense tracker rebuilt as a Flask JSON API (SQLAlchemy + JWT auth) behind a React Native / Expo app, deployed for real: the API runs on Render against an Azure SQL database, the web build is deployed on Vercel, and the app itself also ships as an installable Android APK via EAS Build — not just a localhost demo. Light/dark theming, animated charts, swipe-to-delete, CSV export, and quick-add templates round out the UX.

  • JWT-authenticated Flask REST API (SQLAlchemy + Flask-Migrate) against Azure SQL, deployed on Render with a Dockerized ODBC driver
  • React Native / Expo mobile app — bottom-tab navigation, animated dashboard charts, category filtering, budget tracking
  • Per-user currency preference (12 ISO 4217 codes) persisted server-side, driving every amount shown across the app
  • Light/dark theme with persisted preference, swipe-to-delete, CSV export, pull-to-refresh, and haptic feedback
  • Real Android APK built and distributed via EAS Build, not just an Expo Go preview
  • Web build (Expo for Web) deployed on Vercel, hitting the same Flask API through a locked-down CORS allowlist
  • CORS allowlist and per-endpoint rate limiting on auth routes; pytest suite covering auth, ownership isolation, and CRUD
