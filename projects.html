Smart Resume Analyser

AI-assisted resume scoring, writing tools, and job-matching platform

Upload a PDF, Word or scanned resume and get an OCR + NLP score, an ATS-compatibility check and job-description matching, plus Gemini-powered tools: cover letter, LinkedIn profile, interview prep, and a resume builder with an AI assistant.

Python Flask Postgres NLTK PyMuPDF Tesseract OCR Google Gemini API Docker Render HTML/CSS/JS

▶ How to try it

Create a free account (no email confirmation), upload any resume, then open AI Tools and the Resume Builder.

It runs on a free server that is kept awake, so the first load can take up to a minute. The AI features use Google's free Gemini tier and can say "busy" at peak times; the demo video shows them working.

View detailsHide details

A full-stack Flask application that takes a candidate's PDF, Word or scanned-image resume, extracts its text via OCR and PDF parsing, and analyses it with NLP to produce a scored, section-by-section breakdown — skills, education, experience, and formatting — with an ATS-compatibility check and concrete suggestions for improvement. It also matches a resume against a pasted job description, generates personalised career feedback, and surfaces trends across every resume analysed on an analytics dashboard. An AI Tools page turns an analysed resume into a tailored cover letter (three tones), sharper bullet points, a job-tailoring report, interview practice questions and a LinkedIn profile, all written by Google Gemini from the resume's own facts. A guided resume builder lets users compose a resume from scratch with structured, repeatable work-experience and education entries, an in-app assistant that reviews the draft for gaps and offers rewrites you can apply in one click, and one-click export to a genuinely ATS-parseable PDF with real embedded text rather than a rasterised image. Deployed on Render's free tier against an isolated Postgres schema (Neon) — the first request after a period of inactivity can take up to a minute to wake the instance.

  • OCR + PDF text extraction (PyMuPDF, Tesseract) so both scanned images and native PDFs work
  • NLP-driven skill extraction and section scoring (NLTK tokenisation, stopword filtering, tagging), with education and experience read from their own sections and seniority taken from the dated years
  • ATS-compatibility simulation with a transparent, explainable scoring breakdown
  • Job-description matching to rank a resume's fit against a specific role
  • AI Tools (Google Gemini): cover letter in three tones, bullet improver, job tailoring, interview prep and LinkedIn profile, with the resume and job text treated as untrusted data, input limits, per-user rate limits and plain-text replies
  • Guided resume builder with an in-app AI assistant that flags gaps in the draft and applies suggested rewrites in one click; the server validates every suggestion before the page shows an Apply button
  • Native-text PDF export — real embedded text via direct PDF drawing, not a rasterised image, so builder output is actually machine-readable by real ATS software
  • Auth system with email-based password reset (SendGrid), per-user history and rate-limited sign-in
  • Analytics dashboard (score distribution, top skills, career-field breakdown) with CSV/JSON export for Power BI
  • Frosted monochrome light and dark themes, a keyboard skip link, visible focus rings and 100+ automated tests

A production website for a real cafe business — a React/Vite frontend backed by Vercel serverless functions and a Postgres order log, with an admin dashboard for managing incoming orders and per-drink availability, a live Google Reviews sync, an event Party Cart page with a booking-inquiry builder, a customer-service assistant that can be typed to or spoken to and reads its answers aloud, and full SEO/PWA setup. Deployed and actually in use, not just a demo.

  • Cart-based ordering flow with a built-in step-by-step guide, writing to a Postgres order log via Vercel serverless functions with rate limiting on submission
  • Admin dashboard for managing order status, with CSV export and a recoverable trash bin for deleted orders
  • Live Google Places reviews sync merged with a curated fallback list, capped and text-clamped to keep the section a tidy row of highlights
  • Tri-state per-drink availability (available / unavailable / coming soon) managed from the admin panel, "New" badges for recently added drinks, plus Vercel Analytics
  • Party Cart page for events — four packages, optional add-ons and booking notes, and an inquiry builder that validates the details (date, guest count, venue) and composes a ready-to-send Instagram message, copied or sent in one tap

  • "Ask Mori" customer-service assistant: answers questions about drinks, prices, sweetness and milk options, live open or closed status, ordering, payment and party carts from the site's own data and live availability, and never takes orders itself. Gemini writes the replies when an API key is configured; otherwise (the live demo's current mode) answers come from keyword rules over the same data, so it always responds
  • Voice both ways using the browser's Web Speech API: a Listen button and an optional voice-replies switch read answers aloud, and a microphone button sends a spoken question automatically. Guarded input (500-character cap, 10-turn history, per-client rate limit) and replies stripped of markdown, links and emoji for clean speech

Floss Clinic

Dental clinic platform with real conflict-safe booking, a grounded RAG chatbot and an AI booking assistant

Dental clinic platform with database-enforced conflict-safe booking, two-factor sign-in, a RAG chatbot grounded in the clinic's own documents, and an AI assistant that proposes bookings a patient confirms.

Python Flask SQLAlchemy React Vite sentence-transformers PostgreSQL Gemini

▶ How to try it

Sign in with patient@floss.demo / password123, or create an account.

Staff and admin accounts need two-factor codes, so the patient view is the easy way in.

A full-stack dental clinic platform — appointment booking with genuine double-booking prevention, automatic confirmation and reminder emails, a staff-managed doctor directory, patient records with role-based access, a retrieval-augmented chatbot that only ever answers from the clinic's own documents and refuses to give medical advice, and an AI assistant that can book, move or cancel a patient's own appointments — but only proposes, so nothing changes until the patient presses Confirm. Redesigned end to end with a responsive light and dark interface. Deployed live on Vercel (frontend and API) with Postgres on Neon, with 605 tests (446 backend, 159 frontend) and a CI pipeline running both suites on every push.

  • Appointment booking that rejects real conflicts via a half-open interval check, enforced at the database with a partial unique index — not just an application-level check
  • A RAG chatbot grounded in the clinic's own documents (sentence-transformer embeddings, cosine retrieval, a confidence threshold below which it says "I don't know" instead of guessing), streamed token-by-token
  • An AI booking assistant built as a propose-then-confirm tool loop: the model looks up dentists and open slots but can only propose a change — nothing is written until the patient presses Confirm, which re-checks the slot. Identity comes from the login token, never the model, and Gemini, Groq and Azure OpenAI sit behind one adapter with rate-limit failover
  • Guardrails enforced in code, not just the prompt: security probes, instruction-extraction attempts and requests for other people's data get a fixed reply without reaching the model, and an output guard cuts off any reply that would leak a key, token, database URL or the prompt
  • An auto-regenerating "Dentist & Department Directory" document, chunked one entity at a time so retrieval doesn't dilute across multiple doctors — the chatbot's knowledge base never goes stale when staff update the directory
  • Role-based access (patient / staff / admin / owner) as a signed JWT claim, refreshed on token refresh so a role change takes effect on next login
  • 605 tests (446 backend + 159 frontend), GitHub Actions CI on every push

Expense Tracker

Flask REST API + React Native (TypeScript) app with AI-assisted insights, on Android and the web

A Flask REST API with a React Native (TypeScript) client: type expenses in plain words, get a spending coach and a month-end forecast, and switch between light and dark. Live on Render and Vercel and shipped as an Android APK.

Flask SQLAlchemy JWT React Native Expo TypeScript Postgres Render Vercel Gemini pytest

▶ How to try it

Create a free account (no email confirmation), then tap the + button and try Magic add: type “coffee 15 and taxi 30 yesterday”.

A personal expense tracker built as a Flask JSON API (SQLAlchemy + JWT auth) behind a React Native / Expo (TypeScript) app. Type expenses the way you would say them, and a spending coach turns your history into a month-end forecast, a safe daily amount and the categories that grew. Every number is calculated in Python; when a Gemini key is set the model only words the result, and without one the app falls back to rule-based logic (the live demo runs on that fallback). The API runs on Render against Postgres (Neon), the web build is on Vercel, and the app also ships as an installable Android APK via EAS Build.

  • JWT-authenticated Flask REST API (SQLAlchemy + Flask-Migrate) against Postgres, deployed on Render via Docker
  • Magic add: type “coffee 15 and taxi 30 yesterday” and review the parsed expenses before adding them, plus automatic category suggestions
  • Insights tab: month-end forecast that treats recurring bills separately, a safe daily spend, categories that grew, unusual expenses and a question box
  • AI with guardrails: figures are calculated in Python, Gemini only words them, any answer that invents a number is rejected, and every feature has a rule-based path (the live demo uses it)
  • Auto / Light / Dark appearance that follows the device by default, with an animated add button that respects reduced motion
  • React Native / Expo app — bottom-tab navigation, animated charts, day-grouped history, budget ring with a suggested budget, 12 currencies, CSV export
  • Forgot/reset password flow — a SendGrid-emailed one-time code, hashed and single-use server-side, no account enumeration
  • Real Android APK built via EAS Build, and a web build on Vercel hitting the same API through a locked-down CORS allowlist
  • Rate limiting on auth and AI routes; 110 backend pytest tests covering auth, ownership isolation, CRUD and the AI paths
